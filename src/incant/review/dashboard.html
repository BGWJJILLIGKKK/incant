    Configuration & Settings
    
    
    
      Incant reads configuration hierarchically: base settings from incant.toml and user overrides from incant.local.toml. Changes apply automatically to the next queued job.
    
    

    
    
    
      💡 Common Configuration Examples
      
    
        
    
          Using Local Llama.cpp / Ollama (No Cloud Key)
          
    Set [llm] base_url = "http://localhost:11434/v1" and model name.
    
        
    
        
    
          Using Cloud LLM (Claude or OpenAI)
          
    Set [llm] model = "claude-3-7-sonnet" and put your key in .env.
    
        
    
        
    
          Default Voice Engine
          
    Set [pipeline] synthesize = "kokoro" for fast CPU or "indextts" for GPU.
